# Taylor Rental / Renting Memories Demo

A front-end recreation of rentingmemories.com built as a PartyRentalCRM sales demo.

## Included
- Responsive homepage
- Featured rentals
- Category navigation
- Rental collection pages
- Product detail pages
- Quantity controls and availability-request interaction
- Mobile navigation
- Service, brand, newsletter, social, blog and review sections
- Vite dev/production runner

## Run
```bash
npm install
npm run dev
```

This is a presentation/demo recreation, not the original Shopify source code.
